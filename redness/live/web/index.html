REDNESS

v1.33.7 · Zero Science Lab · powered by Silly Security Inc.

REDNESS is a red-team orchestrator for Active Directory & Windows assessments. It drives NetExec, Impacket and Certipy - it does not reimplement them - normalizes every result into one findings model, and renders it as a live 3D graph and a Word report.

Capabilities: SMB / LDAP / Kerberos / AD CS enumeration (with and without credentials), shares, users, certificate (ESC) issues, TLS weaknesses, AS-REP & Kerberoast hash capture with offline cracking, and NetNTLMv2 capture via LLMNR/NBT-NS poisoning - all fed into loot, the report, and the graph.

Developed byAnja Ivanovska & Gjoko Krstic Contactanja@zeroscience.mk · gjoko@zeroscience.mk Version1.33.7

USAGE

command reference - full docs on the wiki (coming soon)

redness doctor - check which engines/tools are installed.

redness gui - this native window · redness live - browser graph.

redness scan --targets scope.txt -u USER -p PASS -d DOMAIN --wordlist rockyou.txt --out report.docx --live
run the engines against one or many targets (scope file = one IP/host/CIDR per line), capture & crack hashes, write the report, stream the graph.

redness scan --target 10.0.0.10 - a single target, no creds (SMB/TLS/AS-REP).

redness poison --iface eth0 --duration 600 - LLMNR/NBT-NS poisoning to capture NetNTLMv2 (intrusive; opt-in; --analyze to observe only).

redness report findings.json --out report.docx - re-render a saved report.

In the graph: nodes are domain / hosts / users / shares / CAs, colored by finding severity. (Right-click actions - Kerberoast, secretsdump, pass-the-hash - coming.)
