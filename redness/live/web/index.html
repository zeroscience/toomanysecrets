REDNESS

v1.34.0 · Zero Science Lab · powered by Silly Security Inc.

Red-team orchestrator for Active Directory and Windows. It drives NetExec, Impacket and Certipy, folds what they find into one model, and shows it as a live 3D graph and a Word report.

SMB, LDAP, Kerberos and AD CS enumeration with or without creds; shares, users, ESC certificate issues, TLS weaknesses; AS-REP and Kerberoast capture with offline cracking; NetNTLMv2 capture via LLMNR/NBT-NS poisoning. It all lands in loot, the report and the graph.

USAGE

command reference - full docs on the wiki (coming soon)

redness doctor - check which engines/tools are installed.

redness gui - this native window · redness live - browser graph.

redness scan --targets examples/scope.txt -u USER -p PASS -d DOMAIN --wordlist rockyou.txt --out report.docx --live
run the engines against one or many targets (scope file = one IP/host/CIDR per line), capture & crack hashes, write the report, stream the graph.

redness scan --target 10.0.0.10 - a single target, no creds (SMB/TLS/AS-REP).

redness poison --iface eth0 --duration 600 - LLMNR/NBT-NS poisoning to capture NetNTLMv2 (intrusive; opt-in; --analyze to observe only).

redness report findings.json --out report.docx - re-render a saved report.

In the graph: nodes are domain / hosts / users / shares / CAs, colored by finding severity. Right-click a node for enum actions; offensive actions (Kerberoast / secretsdump / DCSync) appear in red when launched with --enable-offensive.
